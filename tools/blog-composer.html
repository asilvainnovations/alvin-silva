5 · Publish

  1. Download both files above.
  2. On GitHub, open assets/data/blog/ in your repo.
  3. Add file → Upload files, then select both downloaded files.
  4. Commit. The post is live once the deploy finishes.
  5. Hard-refresh once (Ctrl/⌘ + Shift + R) — the service worker caches aggressively.
Uploading index.json replaces the manifest, so it must contain every post — which is why this tool loads the live one and merges into it rather than starting from scratch.

Your work is saved in this browser as you type, so closing the tab won't lose it.
