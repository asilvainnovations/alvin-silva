ASilva Form Assistant

One-click form filling for job applications, procurement portals, and institutional forms. Detects fields, maps them to Alvin's structured profile, and suggests content — with full preview, validation, and undo.

Important: This is an assistant, not an auto-submitter. It populates fields for your review. You must verify every field before submitting. Never submit applications without human review. Sensitive fields (salary, etc.) require explicit confirmation.

3 What it does

🔍 Smart Field Detection

Scans the page for text inputs, textareas, and selects. Matches fields using 5 strategies: label text, name attribute, id, placeholder, and heuristic similarity scoring.

📊 Confidence Scoring

Every match shows a confidence percentage (High ≥85%, Medium ≥60%, Low <60%). You decide which fields to fill individually or all at once.

🔒 Sensitive Field Protection

Fields flagged as sensitive (salary, compensation) require explicit confirmation before filling. Never auto-fills passwords or payment fields.

✅ Validation & Warnings

Checks maxlength, pattern, minlength, and type constraints before filling. Warns you if a value will be truncated or doesn't match expected format.

↩️ Undo & Clear

Full undo stack restores original values. Clear button resets all assistant-filled fields in one action. History persists until you close the panel.

🔎 Search & Filter

Type in the search box to filter detected fields by label or data key. Quickly find the field you want to review in long forms.

♿ Accessible Design

Full keyboard navigation (Tab, Shift+Tab, Enter, Escape), ARIA labels, focus trapping, and screen-reader compatible live regions.

🔐 Privacy-First

All data stays in your browser. No external servers, no tracking, no cookies. The bookmarklet is entirely self-contained and runs client-side only.

6 Troubleshooting

The bookmarklet does nothing when clicked

Most likely the bookmark URL was truncated during copy-paste. Browsers silently cut very long URLs. Try the manual installation method above and ensure you copy the entire code block. Alternatively, some corporate browsers block javascript: URLs via Group Policy — in that case, use the extension version (coming soon).

Fields are not detected on a specific page

The assistant matches fields by visible label text, name attribute, id, and placeholder. If a form uses icon-only labels, custom React components without standard HTML attributes, or shadow DOM, detection may fail. Scroll to the form section first to ensure it's in the DOM, then click the bookmark again.

Wrong value mapped to a field

Check the confidence score. Low-confidence matches (<60%) are guesses — always review before submitting. You can also use the Fill button on individual rows instead of Fill All for more control.

How do I update the profile data?

The data is embedded in the bookmarklet itself. To update, regenerate the bookmarklet from this setup page after the JSON source has been updated, then replace your old bookmark with the new one.
