ASilva Form Assistant

One-click form filling for job applications. Detects fields, maps them to Alvin's credentials, and suggests content.

Important: This is an assistant, not an auto-submitter. It populates fields for your review. You must verify every field before submitting. Never submit applications without human review.

Install (one step)

Drag this button up to your browser's bookmarks bar:

💾 ASilva Form Assistant

Clicking it here does nothing on purpose — drag, don't click. Once it's on your bookmarks bar, clicking it there runs it on whatever page you're on.

Bookmarks bar not visible? Press Ctrl+Shift+B (Windows/Linux) or Cmd+Shift+B (Mac) to show it.

How to check it worked: after dragging, open any page with a form (even this one has none, so try a real job application) and click the bookmark. A white panel with a gold border should slide in on the right listing detected fields. If nothing appears, the bookmark's URL may have gotten truncated — try the manual method below instead.

What It Detects

  • Name, Email, Phone, LinkedIn
  • Education / Degrees / Certifications
  • Professional Summary / Bio
  • Skills / Competencies
  • Publications / Research
  • Salary Expectations
  • Availability / Start Date
  • Cover Letter / Why Hire Me

It skips hidden fields, disabled/read-only fields, checkboxes, radio buttons, file uploads, and submit buttons automatically — only text-style fields it can confidently map get suggested.

Using the Panel

  • Fill Field on any single row, or Fill All Fields for everything at once
  • A live counter at the top tracks how many of the detected fields you've filled
  • Clear resets every field the tool touched, if you want to start over
  • Press Esc or click the × to close the panel — it never touches the page again after that

Privacy

All data stays in your browser. No server calls. No tracking. The bookmarklet is self-contained JavaScript that runs entirely client-side — this setup page no longer even fetches a separate file to get the code, so there's nothing that can fail to load.
